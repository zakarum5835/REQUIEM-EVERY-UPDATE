# RUN AWAY! - v1.4.0
This update finally introduces the Apocalypse Era at all costs, improving the game experience while fixing lag spikes, memory leaks while exploring almost every dimensions, except Distant Worlds and The Abyss. Also, the difficult mode has been increased to make this Chapter harder as much as possible to fit with the Apocalypse Era event and finally implemented a new dimension called "Revelations". The Apocalypse Era isn't finished yet.
